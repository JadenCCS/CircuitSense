# CircuitSense

\# CircuitSense

Real-Time Standalone PC Hardware Monitoring Platform



Group: Queue5



\## What it does

CircuitSense is a hardware monitoring device built around a 

Raspberry Pi Zero 2 W with a 3.5-inch TFT display. It connects 

to a Windows or Linux PC and shows live CPU, GPU, RAM, disk, 

network, and uptime stats in real time.
